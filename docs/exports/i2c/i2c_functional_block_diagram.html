Functional Blocks

Register Interface (APB CSR)

Exposes every configuration, status, and data register to the system over a standard APB slave port.

Clock & Reset Manager

Generates the internal functional clock, synchronizes reset domains, and requests the high-speed clock only when the bus actually needs it.

I2C Core — Master & Slave Engine

Implements the I2C protocol state machines for both roles: addressing, clock stretching, arbitration, and SMBus timeout handling.

TX / RX FIFO

Buffers outbound and inbound data bytes between the register interface and the protocol engine.

Interrupt & DMA Controller

Aggregates protocol events into maskable interrupts (standard and NMI) and runs the request/acknowledge handshake for TX and RX DMA.

I2C Bus Interface (Loopback Mux)

Drives the external SCL/SDA lines from whichever engine is active, and supports internal loopback for self-test.

Signal names and directions reflect the IP's top-level port list. Internal net names, FSM states, and register bit-fields are omitted by design — this view describes function, not implementation.
